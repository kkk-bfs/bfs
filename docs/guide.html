使用说明

面向验布班组与现场工程师：从启动软件到完成一匹布的标准操作，以及 CustomUIV3 界面与常见排障要点。

概述

Bullmer 验布机软件（BullmerFabricScanner）运行于 Windows，负责相机采图、AI 疵点检测、PLC/灯带贴标、检验单与 ERP/报告输出。主界面推荐使用 CustomUIV3（SpaceX Ops Console 风格）。

  • 桌面端：安装包发布于 GitHub kkk-bfs/bfs Releases。
  • 在线测试：本站 spacex-main.html 提供 UI 静态预览，不连接真实机台。
  • 帮助页：软件内「帮助」可改大量系统参数；非中文界面可能隐藏帮助入口。

开检与完成

1. 启动前检查

  • 相机网口/USB、PLC、光源、编码器接线正常。
  • 确认机型参数 MachineProject 与现场一致（V1 / V1Sp / Dual 等）。
  • 首次开机建议以管理员权限运行，避免驱动与共享内存权限问题。

2. 登录与建单

  1. 顶栏点击登录，选择检验员（管理员可进调试入口）。
  2. 底栏「新建」创建检验单，填写/扫描缸号、卷号、品名等。
  3. 核对毛/净幅宽、目标米数；需要时打开净幅宽测量（须已开检且机台停稳）。

3. 启动验布

  1. 放好布头，确认布边检测与光源亮度正常。
  2. 点击底栏「启动」。布面滚动后，关注贴标线、疵点列表与报警芯片。
  3. 运行中可用视图开关条隐藏地图/列表，或进入全屏极简模式。

4. 完成

  1. 到米或人工结束时点「完成」，确认弹窗。
  2. 系统写入检验结果并可按工厂配置上传 ERP / 出报告。
  3. 换卷后重复建单或选择历史检验单继续。
贴标或疵点编辑相关弹窗打开时，部分操作要求机台处于停止状态。界面会提示「请先停机」类引导。

UI V3 控件说明

V3 将布面铺满舞台，顶栏、底栏、地图、列表、视图开关条叠在布面上（半透明面板）。可在在线测试中对照。

区域作用要点
顶栏 时间、PLC/相机/光源/幅宽传感器/报警、语言、登录、设置、关于、退出 设备芯片可点开对应调试/状态弹窗
疵点地图 整匹疵点分布预览 极简模式下缩为窄条
疵点列表 条目浏览；新增/编辑 编辑/新增需停机
视图开关条 地图、列表、贴标线、布边、检测结果、网格、适配宽高、全屏 位于底栏上方居中；左侧 FPS、右侧坐标
底栏 检验单信息、启停/完成、码表（米长/幅宽/速度等）、进度与报警 全屏极简时改为紧凑单行

全屏极简

点击视图开关条最右侧「全屏」：顶底栏变矮、地图/列表变窄、运行方向指示隐藏，便于盯布。再点一次退出。

坐标与帧率

  • FPS：「显示」为界面绘制帧率，「入」为入帧速率。
  • 坐标：鼠标在布面上移动时显示原图像素与物料毫米；移出后隐藏。

疵点处理

自动检测

模型检出结果进入检测队列，可在视图开关中单独开关「检测结果」「有效疵点」「过滤疵点」「疵点信息」图层。

人工新增 / 编辑

  1. 机台停止后，在列表点「新增」或「编辑」。
  2. 选择类型、等级、位置；有触摸笔时可点选布面定位。
  3. 保存后列表、地图与布面框同步刷新。

四分制

底栏「百平方码扣分」芯片显示当前累计；可打开四分制详情查看分档与合格线。破损类疵点可配置固定记 4 分。

设备联调

  • PLC：顶栏 PLC 芯片或调试工具查看寄存器、速度、张力；备份/恢复寄存器前请确认机台空闲。
  • 相机：确认采图帧率与分辨率；模拟模式 IsTestMode 可用于无真机联调 UI。
  • 光源：自动调光参数可在帮助页调整；改串口后可能需重开光源或重启。
  • 幅宽传感器 / 视觉幅宽：按工厂开关启用；净幅宽测量有「需已开检」「需停机」前置条件。

升级与排障

安装包

  • 主安装包：setup_BullmerFabricScanner_slim_*.exe（GitHub Releases）。
  • 亦可仅更新 views / erpinterface 增量包（现场按需）。
  • importance=2 的云端版本会在启动时强制下载安装并重启。

常见问题

  • Driver not loaded（MySQL）：确认安装包含 libmysql.dll 与 sqldrivers/qsqlmysql.dll。
  • OpenCV 缺失：确认 opencv_world480.dll 已随 slim 包安装。
  • 推理闪退：检查 YoloApi_yolov8_1_EnableReload，默认建议关闭热重载。
  • CEF 页面空白：确认 locales 与 libcef 资源完整。

FAQ

在线测试能控制真机吗？

不能。静态页仅演示 UI 与弹窗交互，数据为本地演示值。

如何切换语言？

顶栏语言下拉（中文 / English / 越南语 / 葡萄牙语 / 德语）。部分帮助页仅中文完整。

贴标弹窗时点了启动？

V3 会尝试消费「启动」为继续验布（跳过关窗），避免误走继续检测逻辑；具体以当前版本行为为准。
